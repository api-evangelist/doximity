Doximity Dialer Enterprise users can now add on-demand professional interpreters — including video, audio, and ASL interpreters — directly to an active Dialer Video call via Doximity's integration with LanguageLine Solutions for select clients. Select a language from 300+ options and a certified interpreter joins as a video participant all without leaving the platform. Currently available on desktop only; mobile support is coming soon.
